# Chapter 03 명령어

| Term & Category                         | Definition, Role & Example                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| :-------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **고급 언어** _(High-Level)_            | 사람이 이해하고 작성하기 쉽게 만들어진 언어 (C, Python, Java 등).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **저급 언어** _(Low-Level)_             | 컴퓨터가 직접 이해하고 실행할 수 있는 코드.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **저급 언어의 종류** _(Types)_          | • **기계어:** 0과 1로 이루어진 명령어로 구성.<br>• **어셈블리어:** 기계어를 사람이 읽기 편한 형태로 번역한 언어.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **컴파일 언어** _(Execution)_           | 컴파일러에 의해 소스 코드 전체가 저급 언어로 변환되어 실행되는 언어 (C, C++).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **인터프리터 언어** _(Execution)_       | 인터프리터에 의해 소스 코드가 한 줄씩 저급 언어로 변환되어 실행되는 언어 (Python, JS).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **명령어 구조** _(Instruction)_         | • **연산 코드 (Operation code):** 명령어가 수행할 연산을 의미.<br>• **오퍼랜드 (Operand):** 연산에 사용할 데이터 또는 연산에 사용할 데이터가 저장된 위치를 의미.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **주소 지정 방식** _(Addressing Modes)_ | 연산에 필요한 데이터(유효 주소)를 참조하는 방식:<br>• **즉시 주소 지정 방식(immediate addressing mode):** 오퍼랜드 필드에 실제 데이터를 직접 명시.<br>• **직접 주소 지정 방식(direct addressing mode):** 유효 데이터가 위치한 실제 메모리 주소를 명시.<br>• **간접 주소 지정 방식(indirect addressing mode):** 유효 메모리 주소를 가리키는 메모리 주소를 명시.<br>• **레지스터 주소 지정 방식(register addressing mode):** 유효 데이터가 저장된 레지스터 번호를 명시.<br>• **레지스터 간접 주소 지정 방식(register indirect addressing mode):** 유효 데이터의 메모리 주소를 저장하고 있는 레지스터를 명시. |
