# Chapter 05 CPU 성능 향상 기법

클럭 속도가 높은 CPU는 빠르게 동작한다.

| Term & Category                                                  | Definition, Role & Example                                                                                                                                                                                                                                                                                              |
| :--------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **클럭 속도를 높이는 방법**                                      | CPU의 코어와 스레드 수를 늘리기                                                                                                                                                                                                                                                                                         |
| **코어**                                                         | CPU 내에서 명령어를 실행하는 부품                                                                                                                                                                                                                                                                                       |
| **멀티코어** _(multi-core)_                                      | 여러 개의 코어를 포함하는 CPU(멀티코어 프로세서)                                                                                                                                                                                                                                                                        |
| **스레드**                                                       | 실행 흐름의 단위<br>• **하드웨어적 스레드:** 하나의 코어가 동시에 처리하는 명령어 단위.<br>• **소프트웨어적 스레드:** 하나의 프로그램에서 독립적으로 실행되는 단위.                                                                                                                                                     |
| **멀티스레드(multithread) 프로세서**                             | 하나의 코어로 여러 개의 명령어를 동시에 실행할 수 있는 CPU                                                                                                                                                                                                                                                              |
| **명령어 병렬 처리 기법** _(ILP; Instruction-Level Parallelism)_ | 명령어를 동시에 처리하여 CPU를 한시도 쉬지 않고 작동시키는 방법<br>• **명령어 파이프라이닝:** 동시에 여러 개의 명령어를 겹쳐 실행하는 기법.<br>• **슈퍼스칼라:** 여러 개의 명령어 파입프라인을 두는 기법.<br>• **비순차적 명령어 처리 기법:** 파이프라인의 중단을 방지하기 위해 명령어를 순차적으로 처리하지 않는 기법. |
| **명령어 집합 구조** _(ISA; Instruction Set Architecture)_       | CPU의 언어이자 하드웨어가 소프트웨어를 어떻게 이해할지에 대한 약속<br>• **CISC(Complex Instruction Set Computer):** 복잡하고 다양한 종류의 가변 길이 명령어 집합을 활용.<br>• **RISC(Reduced Instruction Set Computer):** 단순하고 적은 종류의 고정 길이 명령어 집합을 활용.                                                                                                                |
