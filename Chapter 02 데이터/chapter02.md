# Chapter 02 데이터

| Term & Category               | Definition, Role & Example                                                                                                   |
| :---------------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **비트**                      | 0과 1로 표현할 수 있는 가장 작은 정보 단위이다.                                                                              |
| **이진법**                    | 1을 넘어가는 시점에 자리 올림하하여 0과 1만으로 수를 표현하는 방법이다.                                                      |
| **이진법에서 음수 표현 방법** | 2의 보수                                                                                                                     |
| **십육진법**                  | 15를 넘어가는시점에 자리 올림하여 수를 표현하는 방법이다.                                                                    |
| **문자집합**                  | 컴퓨터가 인식할 수 있는 문자의 모음으로, 문자 집합에 속한 문자를 인코딩하여 0과 1로 표현할 수 있다.                          |
| **EUC-KR**                    | 한글을 2바이트의 크기로 인코딩할 수 있는 완성형 인코딩 방식                                                                  |
| **유니코드**                  | 여러 나라의 문자들을 광범위하게 표현할 수 있는 통일된 문자 집합이며, UTF-8. UTF-16- UTS31는 유니코드 문자의 인코딩 방식이다. |
