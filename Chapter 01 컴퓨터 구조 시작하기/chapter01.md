# Chapter 01 컴퓨터 구조 시작하기

| Term & Category                     | Definition, Role & Example                                                                                                                                                                       |
| :---------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **컴퓨터의 핵심 부품**              | 중앙처리장치(CPU), 주기억장치(메모리), 보조기억장치(secondary storage), 입출력장치(input/output(I/O) device)                                                                                     |
| **메모리** _(main memory)_          | 현재 실행되는 프로그램의 명령어와 데이터를 저장하는 부품이다. (e.g., `RAM(Random Access Memory)`, `ROM(Read Only Memory)`)                                                                       |
| **CPU** _(Central Processing Unit)_ | 메모리에 저장된 명령어를 읽어 들이고, 읽어 들인 명령어를 해석하고, 실행하는 부품이다. (e.g., `산술논리연산장치(ALU; Arithmetic Logic Unit)`, `레지스터(Register)`, `제어장치(CU; Control Unit)`) |
| **보조기억장치**                    | 전원이 꺼져도 보관할 프로그램을 저장하는 부품이다.                                                                                                                                               |
| **입출력장치**                      | 컴퓨터 외부에 언결되어 컴퓨터 내부와 정보를 교환할 수 있는 부품이다.                                                                                                                             |
| **시스템 버스** _(Hazards)_         | 컴퓨터의 네 가지 핵심 부품들이 서로 정보를 주고 받는 통로이다.                                                                                                                                   |
